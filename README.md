# Browser Extension Tool

A browser extension project designed to improve workflow, productivity, and web-based repetitive tasks.

## Features

- Browser-based helper functions
- Productivity-oriented workflow support
- Page interaction features
- Lightweight extension structure
- Expandable popup and background script architecture

## Tech Stack

- JavaScript
- HTML
- CSS
- Browser Extension APIs

## Purpose

This project is built to simplify repetitive browser-side operations and provide a practical extension-based workflow tool.

## Installation

1. Download or clone this repository
2. Open your browser's extension management page
3. Enable Developer Mode
4. Choose **Load unpacked**
5. Select the project folder

## Notes

- Do not upload private API keys or sensitive tokens
- Keep test credentials out of the repository
- Use only in authorized and legitimate workflows
